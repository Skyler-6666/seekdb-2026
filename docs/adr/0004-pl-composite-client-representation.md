# PL 复合值在客户端输出边界转换为 JSON 文本

UNNEST 的内部记录和集合保持为单个列值，而现有 MySQL 客户端输出路径缺少 PL 复合值编码。为保持列名和列数契约并让现有客户端直接读取结果，SQL 内部保留有类型的值，由通用结果输出层在最终输出时编码为一个 JSON 文本单元格，记录采用对象、顺序集合采用数组，整个值为 NULL 时发送 SQL NULL；同类型值不论来自何种表达式均使用相同规则，表函数只交付列值，不参与序列化。DESCRIBE 展示逻辑声明，协议元数据描述实际文本表示，普通和打包输出、文本和二进制协议必须遵守相同契约；此能力作为独立配套任务实现，具体规则见[客户端输出设计](../design/pl-composite-client-output.md)。
