# 通过内建表函数暴露现有虚拟表的数据

为消除虚拟表自身的 schema 对象及其元数据落盘开销，将现有虚拟表的查询能力接入独立命名的内建表函数，逐项核对能力去向；初期可一一映射，语义核对后允许合并，由必要的视图投影/筛选保留输出与权限约定，避免将旧 VT 的历史划分固化为永久接口。函数名、参数和输出列定义随程序发布并注册，不通过 `CREATE FUNCTION` 或持久化表对象建立身份；代价是这些内建定义的变更需要通过产品发布管理。本轮仅建设内建表函数，并仅消除虚拟表自身的对象定义：保留的系统视图改为查询表函数，其自身 schema、底层真实数据和用户对象的持久化不在消除范围内。

此决策在第一轮确认，2026-10-17 架构复核将严格一一映射修订为能力覆盖；具体约束见[设计文档](../design/table-functions.md#71-入口类别映射)。当前交付为设计文档，尚未实施。
