# 表函数共用绑定接口，允许扫描产行或查询展开

内建表函数通过共同注册与绑定入口提交输出列、参数约束和对象依赖，普通 `FROM f(...)` 不依赖逐函数的语法或 resolver 分支；JSON_TABLE 的专属语法通过结构化适配接入。绑定阶段接纳扫描定义或查询展开：扫描形成统一函数扫描关系，展开经普通查询绑定后成为派生表，两者在绑定结束时都接入现有关系表示、列绑定、权限和依赖机制，不新增贯穿优化与执行的双分支表函数关系管理。这保留了 HYBRID_SEARCH 的查询展开和系统信息的数据访问能力；展开阶段不执行数据查询，展开后也不保留可执行的表函数包装。
